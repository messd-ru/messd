# MESSD — правила для агентов

Перед работой прочитайте документацию в `.docs/` (начните с `.docs/README.md`).

## Turborepo

Конфигурация и команды `turbo` зависят от установленной версии. Перед изменением `turbo.json`, скриптов или CI читайте документацию из пакета: `node -p "require.resolve('turbo/package.json')"`, затем `docs/README.md` рядом с ним. Навык `skills/turborepo` описывает тот же порядок.

## Правила кода

- Только TypeScript, Node.js 24 (см. `.nvmrc`), pnpm-воркспейсы.
- Комментарии в коде запрещены.
- Форматирование — Prettier из корня (`pnpm format`), линтинг — общий `@messd/eslint-config`.
- Внутри пакета импорты через `#…` с расширением файла (`#shared/lib/format.ts`), между пакетами — без расширения (`@messd/contracts/room`).
- Бэкенд строится по MVC: `models` — данные и доменная логика, `controllers` — обработчики, `views` — сериализация ответов.
- Фронтенд модульный: `pages/<домен>` не импортируют друг друга, общее живёт в `shared`.
- Новые зависимости — только активно поддерживаемые (релиз не старше года).
- Любое изменение поведения сопровождается тестом Playwright в `tests/e2e`.

## Проверка перед сдачей

```sh
pnpm lint && pnpm typecheck && pnpm format:check && pnpm test
```
