# Тестирование

Все тесты — Playwright в пакете `tests/e2e`.

| Проект             | Что проверяет                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------- |
| `api`              | REST API: гости, комнаты, контакты, валидация, авторизация                                    |
| `signaling`        | Протокол WebSocket: роли, модерация, приглашения, пересылка ключей, транспорты                |
| `desktop-chromium` | Интерфейс 1280×800 с фейковыми камерой и микрофоном, звонки из нескольких браузеров           |
| `mobile-chromium`  | Тот же интерфейс в мобильной раскладке 390×844                                                |
| `desktop-firefox`  | Интерфейс в Firefox (фейковые медиа через настройки браузера)                                 |
| `desktop-webkit`   | Интерфейс в WebKit без тестов с медиа (`@media`), так как WebKit не умеет фейковые устройства |

Сценарии звонков поднимают по 2–3 независимых браузерных контекста. Они проверяют, что видео действительно декодируется после сквозного шифрования, что раскладки и состояния соответствуют макету, а также работу чата, рук, модерации и ухода собеседника.

## Запуск локально

```sh
docker compose up -d postgres
pnpm --filter @messd/e2e exec playwright install
pnpm test
```

Playwright сам поднимает `api` (3100), `core` (4100, медиа с 40100) и `web` (5180), поэтому тесты не мешают `pnpm dev`. База берётся из `DATABASE_URL` (по умолчанию локальная из `compose.yaml`).

Отдельный проект или файл:

```sh
pnpm --filter @messd/e2e exec playwright test --project=desktop-chromium specs/ui/call.spec.ts
```

## Запуск в контейнере

```sh
docker compose --profile test run --rm e2e
```

Образ основан на официальном `mcr.microsoft.com/playwright` и запускает все проекты, включая Firefox и WebKit. Отчёт сохраняется в `tests/e2e/playwright-report`.
