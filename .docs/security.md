# Безопасность

## Шифрование медиа

Медиа шифруется на двух уровнях.

1. **Транспорт.** WebRTC всегда использует DTLS-SRTP между браузером и сервером mediasoup.
2. **Сквозное шифрование (E2EE).** Каждый кадр аудио и видео шифруется в браузере отправителя и расшифровывается только у получателей. Сервер пересылает кадры, не имея ключей.

### Как устроено E2EE

- При входе клиент создаёт пару ключей ECDH P-256 и случайный ключ отправителя AES-GCM-128.
- Открытый ключ ECDH передаётся в `join` и виден остальным участникам.
- Каждому участнику клиент отправляет свой ключ отправителя, зашифрованный общим ключом ECDH (AES-GCM-256). Сервер лишь пересылает сообщение `e2eeKey` адресату.
- Кадры обрабатывает Web Worker через Encoded Transform: `RTCRtpScriptTransform` (Safari, Firefox, Chrome) или Insertable Streams (старые версии Chromium). Заголовок кадра (VP8 — 10 байт для ключевого и 3 для разностного, Opus — 1 байт) остаётся открытым, чтобы SFU мог выбирать слои. Остальное шифруется AES-GCM, заголовок служит дополнительными данными аутентификации, в конец кадра дописываются IV и номер ключа.
- Когда участник выходит, оставшиеся меняют ключи отправителя (с задержкой 1,5 с, чтобы новый ключ успел дойти). Вышедший не сможет расшифровать дальнейший звонок.
- Сообщения чата шифруются тем же ключом отправителя и нигде не хранятся.

### Код безопасности

Сервер распространяет открытые ключи, поэтому теоретически может их подменить (атака «человек посередине»). Для проверки в интерфейсе есть код безопасности — подсказка у значка замка. Это хеш SHA-256 от всех открытых ключей звонка. Если код у участников совпадает, ключи не подменены.

Если браузер не поддерживает Encoded Transform, значок показывает открытый замок и «Транспортное шифрование».

## Сеть

- Сайт, API и сигнализация доступны только по HTTPS/WSS (Caddy, HSTS).
- `core` принимает WebSocket только с разрешённых origin (`APP_ORIGINS`).
- TURN выдаёт временные учётные данные (TURN REST API, HMAC-SHA1 общего секрета, срок `TURN_TTL_SECONDS`). Реле во внутренние сети и loopback запрещено.
- Заголовки Caddy: строгая CSP (без внешних источников и inline-скриптов), `X-Frame-Options: DENY`, `Permissions-Policy` только для своего origin.

## Гостевые сессии

- Токен — 256 случайных бит. В базе хранится только его SHA-256.
- Создание гостей и комнат ограничено по IP (`@fastify/rate-limit`).
- Создатель комнаты может выключить чужой микрофон и удалить участника. Удалённый гость не может вернуться в эту комнату.

## Сторонние сервисы

Приложение ничего не загружает извне: шрифт Raleway, иконки, модель сегментации и WebAssembly MediaPipe поставляются вместе со сборкой. Внешний сервис только один — Let's Encrypt для сертификата, его запрашивает Caddy.
