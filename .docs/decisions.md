# Решения и отступления

## Стек

| Требование ТЗ            | Решение                                                                        | Почему                                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Последний React Router 7 | `react-router@7.18`                                                            | Последняя версия — уже 8.x, но ТЗ требует 7. Используется data-роутер (SPA)                                                                     |
| TypeScript               | `typescript@6.0`                                                               | TypeScript 7 вышел, но `typescript-eslint` пока поддерживает версии ниже 6.1                                                                    |
| shadcn/ui                | Компоненты shadcn на Radix в `packages/ui`, варианты через `tailwind-variants` | `class-variance-authority`, на котором построены компоненты shadcn, не обновлялся больше года — по ТЗ такие библиотеки запрещены                |
| Общий Prettier и ESLint  | `.prettierrc.json` в корне и пакет `@messd/eslint-config`                      | `eslint-config-prettier` не обновлялся больше года. Правила форматирования в используемых конфигурациях ESLint не включены, поэтому он не нужен |
| React Compiler           | `@rolldown/plugin-babel` + `reactCompilerPreset()` из `@vitejs/plugin-react`   | Стабильный путь. Нативный Rust-компилятор помечен как экспериментальный                                                                         |
| Node.js LTS              | 24 (`.nvmrc`)                                                                  | Актуальная LTS-ветка. Бэкенд выполняет `.ts` напрямую, без сборки                                                                               |
| Redis                    | Не используется                                                                | Состояние звонков живёт в памяти `core`, а масштабирование — вертикальное (воркеры mediasoup по ядрам)                                          |
| SFU                      | mediasoup внутри `core`                                                        | Библиотека для Node.js: остаётся «чистым Node.js», без отдельного медиасервера и внешних сервисов                                               |
| Dev и prod Dockerfile    | Один многоэтапный `Dockerfile` на приложение с целями `dev` и `prod`           | Рекомендация Docker best practices: общие слои и кеш, нет дублирования                                                                          |

## Продукт

- **Без регистрации.** При первом визите гость вводит имя. Сервер выдаёт токен, он хранится в `localStorage`. Имя можно изменить, нажав на него в приветствии на главной: в макете профиля нет, это открытый вопрос дизайна.
- **Поиск человека.** Аккаунтов нет, поэтому поиск идёт среди людей, с которыми гость уже созванивался (таблица `contacts`). «Позвонить» создаёт комнату и отправляет собеседнику входящий звонок, если он онлайн. Иначе приложение предлагает отправить ссылку.
- **Код комнаты.** Сервер генерирует коды вида `abc-defg-hij`. Поле «Войти по ссылке» принимает и полную ссылку с любым доменом, и голый код.
- **Склонения имён.** Макет использует падежи («Звонок с Аней», «Ждём Аню», «Аня покинула звонок»). Пол и падежные формы произвольного имени неизвестны, поэтому тексты сформулированы нейтрально: «Аня уже в комнате и ждёт вас», «Ждём собеседника», «Собеседник покинул звонок».
- **Мобильное «Открыть настройки» (2i).** Веб-страница не может открыть системные настройки телефона. Кнопка открывает шторку с пошаговой инструкцией для текущего браузера и «Проверить снова».
- **Мобильное лобби (1i).** По ТЗ нужна кнопка «Только голос», поэтому под «Подключиться» добавлена второстепенная кнопка.
- **Чат, реакции и демонстрация экрана.** Экраны для них в макете не нарисованы. Чат — боковая панель (на мобильном — шторка) в стиле панели участников. Реакции — всплывающие эмодзи. Демонстрация экрана переводит звонок в раскладку «говорящий крупно» с экраном в главной области.
- **Название групповой комнаты.** Создание комнаты с названием в макете не предусмотрено, поэтому в шапке показываются имена участников («Аня, Папа и ещё 3»).
- **Выбор динамика.** Выбор аудиовыхода зависит от `setSinkId`. Где браузер его не поддерживает (Safari, большинство мобильных), список неактивен и звук идёт в системное устройство.
- **Максимум участников** — `MAX_PEERS` (по умолчанию 50). Сетка постраничная, по 6 плиток на странице.
