# REST API (`apps/api`)

Базовый путь — `/api`. Тела запросов и ответов — JSON и валидируются схемами из `@messd/contracts/api`. Защищённые маршруты требуют заголовок `Authorization: Bearer <token>` — токен выдаётся при создании гостя.

| Метод | Путь                   | Доступ | Описание                                                                       |
| ----- | ---------------------- | ------ | ------------------------------------------------------------------------------ |
| GET   | `/api/health`          | все    | Проверка здоровья: `{ "status": "ok" }`                                        |
| POST  | `/api/guests`          | все    | Создать гостя. Тело `{ name }` → `201 { guest, token }`                        |
| GET   | `/api/guests/me`       | гость  | Текущий гость → `{ guest }`                                                    |
| PATCH | `/api/guests/me`       | гость  | Сменить имя. Тело `{ name }` → `{ guest }`                                     |
| POST  | `/api/rooms`           | гость  | Создать комнату → `201 { room }`                                               |
| GET   | `/api/rooms/:code`     | все    | Комната → `{ room }` или `404 { reason: "not_found" \| "ended" }`              |
| GET   | `/api/contacts?query=` | гость  | До 8 людей, с которыми гость созванивался, с поиском по имени → `{ contacts }` |

## Модели

```ts
Guest = { id: uuid, name: string }
Room = { code: string, creatorId: uuid, createdAt: ISODate }
Contact = { id: uuid, name: string, lastCallAt: ISODate }
```

Имя гостя — 1–40 символов после обрезки пробелов. Код комнаты — строчные латинские буквы и цифры через дефис, 3–48 символов. Сервер генерирует коды вида `abc-defg-hij`.

## Ошибки

| Код | Когда                                                                           |
| --- | ------------------------------------------------------------------------------- |
| 400 | Не прошла валидация (`message` содержит путь и причину)                         |
| 401 | Нет или неверный токен                                                          |
| 404 | Комната не найдена или завершена                                                |
| 429 | Превышен лимит создания гостей и комнат (`RATE_LIMIT_MAX` в минуту с одного IP) |

## Устройство

MVC:

- `models/` — запросы Drizzle (`guest.model.ts`, `room.model.ts`, `contact.model.ts`);
- `controllers/` — обработчики маршрутов;
- `views/` — преобразование строк БД в ответы;
- `routes.ts` — регистрация маршрутов со схемами Zod (`fastify-type-provider-zod`);
- `plugins/auth.ts` — проверка гостевого токена.
